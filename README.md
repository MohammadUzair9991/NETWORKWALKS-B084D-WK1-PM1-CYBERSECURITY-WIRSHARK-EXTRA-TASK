## 📌 Project Overview
This project focuses on analyzing network traffic using **Wireshark** to understand IP addressing, DNS resolution, TLS communication, and secure HTTPS connections.

The objective is to identify network information and examine how a secure connection is established between a laptop and the website `networkwalks.com`.

## 🎯 Objectives
- Identify the laptop's IP address.
- Identify the DNS server IP address.
- Find the IP address of `networkwalks.com`.
- Analyze the TLS Client Hello packet.
- Identify the secure server port.
- Determine the TLS version used by the website.

## 🔍 Practical Questions & Answers

### 1. What is the IP address of your own laptop?
**Answer:** `YOUR_LAPTOP_IP`

### 2. What is the IP address of your DNS server?
**Answer:** `YOUR_DNS_SERVER_IP`

### 3. What is the IP address of the website networkwalks.com?
**Answer:** `WEBSITE_IP_ADDRESS`

### 4. Which website name (Server Name) is sent in the TLS Client Hello?
**Answer:** `networkwalks.com`

### 5. Which server port is used for the secure connection?
**Answer:** `443 (HTTPS)`

### 6. Which TLS version does the website use?
**Answer:** `YOUR_TLS_VERSION`
