## 📌 Project Overview

This project demonstrates practical network traffic analysis using Wireshark. The objective is to investigate DNS queries, IP address resolution, and TLS handshake communication by analyzing captured network packets.

## 🎯 Objectives

1. Identify the laptop's IP address used during packet capture.
2. Identify the DNS server IP address.
3. Find the IP addresses returned by DNS for `microsoft.com`.
4. Identify the Server Name (SNI) in the TLS Client Hello.
5. Identify the secure server port.
6. Determine the TLS version used by the website.
